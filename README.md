# SwiterBank
It's an application to simulate a bank application (without database and security).

## Login
To do the first login, put account id with 4 characters (ex : id 1 -> 0001; id 10 -> 0010; etc...)
Your password is mdp + id (ex : id 0010 -> mdp0010).

## Operations
You can simulate transactions (to deposit, withdraw or transfer money), change an account name or an account password.
